# AI-Era Career Experiment Skill

A five-step classroom coaching exercise: **Major → Minor → Real Problem → AI-Assisted Build → Evaluation**.

## For students
Open [STUDENT_PROMPT.md](STUDENT_PROMPT.md), copy it into a fresh ChatGPT conversation, and answer each question. No installation required.

## Skill file
[SKILL.md](SKILL.md) contains reusable instructions for environments that support custom Skills. Download this folder or the repository ZIP, and place it in your environment's Skills location per its documentation. Simply downloading a Skill does not mean it is automatically installed in every ChatGPT account.

## Example
- Major: Strategic communication.
- Minor: Data analytics, to connect messaging to audience behavior.
- Problem: A hypothetical nonprofit has engagement but low volunteer sign-ups.
- Build: Prototype a campaign dashboard using clearly marked synthetic data.
- Evaluate: Get stakeholder feedback and, with approval, measure relevant conversion rates.

Keep hypothetical data labeled, respect privacy, and never claim tested outcomes without real evidence.
