# Contributing

Contributions should improve respectful, low-risk learning for graduate students pursuing eligible entry-level roles.

1. Read `references/safety.md` and `references/case-template.md`.
2. Use original material, properly licensed material, or cited public facts. Never submit confidential, leaked, or NDA-protected interview content.
3. Fictionalize organizations, people, contexts, and data. Current inspiration must become a substantially new scenario.
4. Include a tailored framework, an alternative valid approach, checked calculations, assumptions, provenance, and the standard student-first checkpoint.
5. Run both scripts in `scripts/`.

Submitting a case asserts that you have the right to contribute it. Maintainers review pedagogy, calculations, provenance, bias, and student comfort. Automated checks do not replace human review.
