# Case authoring template

Create a directory under `cases/<case-id>/` containing `metadata.yaml`, `case.md`, and `solution.md`.

## Candidate file

Include a fictional organization, decision, objective or success measure, neutral opening facts, the standard 1–2 clarifying-question invitation, and interviewer facts marked for staged disclosure.

## Solution file

Include:

1. a tailored reference framework;
2. a credible alternative organization;
3. math/formulas to disclose only after the student's framework;
4. fully checked calculations;
5. evidence interpretation;
6. recommendation, risks, and next step;
7. case-specific rubric notes when needed.

Run `python3 scripts/validate_cases.py`. Automated checks supplement rather than replace human safety and pedagogy review.
