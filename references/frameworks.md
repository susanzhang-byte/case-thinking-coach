# Framework construction guide

Start with the decision and success metric. Build 3–5 top-level branches whose answers would change the recommendation. Prioritize a branch using the initial facts and explain why.

## Reusable building blocks

- **GTM:** need; proposition; economics; channel/launch plan; capabilities and risks.
- **Pricing:** objective; customer value; alternatives; unit economics/volume; implementation.
- **Brand:** current perception; target customer; competitive frame; promise/proof; activation and measurement.
- **Growth:** baseline; core penetration; new customers/products/geographies/channels; economics; risks.
- **Marketing ROI:** objective/baseline; audience/funnel; incremental impact; economics; allocation/experimentation.
- **Profitability:** revenue tree; variable/fixed costs; segment drivers; root causes; feasible actions.
- **Operations/turnaround:** performance gap; demand/service; process/capacity; cost/productivity; implementation sequence.
- **Communications:** objective; stakeholders; perception; message/proof; channel/timing; measurement.
- **Safe crisis:** verify; stakeholder impact; immediate containment; message/messenger; cadence; recovery.

These are ingredients, not mandatory headings. A stakeholder map, funnel, timeline, or system model may outperform a strict MECE tree. Penalize overlap only when it causes confusion or double-counting.
