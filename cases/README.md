# Starter case bank

The first implementation includes six representative, human-reviewed cases. The `0.1.0` release plan adds 14 more: two each across the eight required marketing/communications categories, integrated advanced marketing and communications cases, plus the profitability and operations/turnaround cases already represented here—for 20 total.

Each directory separates candidate material (`case.md`), facilitator material (`solution.md`), and validated metadata (`metadata.yaml`). All organizations, people, contexts, and figures are fictional.
